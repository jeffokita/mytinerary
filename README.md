# Mytinerary

An end-to-end trip planner: get inspired, plan around a few anchor activities per day, follow the plan on the trip, and look back afterward.

The whole app is one file, `mytinerary/index.html`. It's built to run as a claude.ai artifact, where it uses Claude for trip ideas, the travel-profile chat and filling in itineraries.

- **Live AI:** open the file as an artifact on claude.ai.
- **Demo:** the GitHub Pages site always uses sample data.
- **Locally:** run `python3 -m http.server 8765 -d mytinerary`, then open http://localhost:8765/?mock
